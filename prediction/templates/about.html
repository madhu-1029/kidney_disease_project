About the Project

KidneyAI is a Machine Learning based kidney disease prediction system developed to analyze important patient health information and predict the possible kidney disease category.

The system accepts selected patient parameters such as age, gender, BMI, blood pressure, serum creatinine, eGFR, urine albumin and other relevant health information.

The entered information is processed by a trained Machine Learning model, which predicts one of the predefined kidney condition categories.

🎯

Project Objective

The main objective of KidneyAI is to provide a simple interface where patient information can be entered and analyzed using a trained Machine Learning model.

🤖

Machine Learning

The system uses a trained Random Forest Machine Learning model to classify patient information into different kidney disease categories.
